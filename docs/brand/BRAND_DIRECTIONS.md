# BreachGym Brand Directions

> **Implemented:** Direction D — Night Docket (lean). See `NIGHT_DOCKET_LEAN.md`.

Research basis (2026): Harvey (warm near-black + serif restraint, almost no accent), Spellbook (obsidian + ownable secondary system), Clio (institutional blue). Firm LMS tools (Intellek/Profiscience) skew corporate-generic. BreachGym must feel partner-serious *and* unmistakably AI/adaptive — without Duolingo pastels or generic SaaS purple.

## Direction A — Reporter Signal
- **Positioning:** Law-reporter editorial × precision AI signal
- **Palette:** Canvas `#0B1220` · Parchment `#F4F0E6` · Ink `#12141A` · Signal cobalt `#2F6FED` · Muted `#8B93A7`
- **Type:** Serif display + geometric sans
- **AI cue:** Cobalt used only for Adaptive / live / primary actions
- **Avoids:** Harvey warm-black clone; Clio sky-blue; game XP chrome

## Direction B — Chambers Brass
- **Positioning:** Modern chambers library
- **Palette:** Bottle `#0C1F1A` · Cream `#F7F3EB` · Brass `#B8954A` · Charcoal `#1C1917`
- **Type:** Classical serif + humanist sans
- **AI cue:** Brass as hairline technology, not jewelry bling
- **Risk:** Can read “legacy firm brochure” if brass is overused

## Direction C — Ink Terminal
- **Positioning:** Bloomberg discipline × fountain-pen legal craft
- **Palette:** Limestone `#E9E7E2` · Ink `#141210` · Pen teal `#0E6B66` · Alert `#9A3412` (rare)
- **Type:** Condensed sans + monospace for state/clock codes
- **AI cue:** “LIVE ADAPTIVE” teal indicator + matrix density
- **Fit:** Strongest for weak-state matrices and adaptive queues

## Direction D — Night Docket
- **Positioning:** Ownable dark identity with copper “live” metal
- **Palette:** Aubergine `#160F1A` · Limestone `#F2EDE5` · Copper `#B87333` · Ivory `#F7F4EE`
- **Type:** Editorial serif + clean sans
- **AI cue:** Copper for Adaptive / AI moments only
- **Fit:** Most distinctive brand mark; farthest from Clio/Harvey defaults

## Recommendation (non-binding)
For BreachGym’s multi-state seam drills + Adaptive Review, **A or C** best marry seriousness with tech signal; **D** if maximum brand distinctiveness is the priority; **B** if prestige/tradition is the primary buyer emotion.
